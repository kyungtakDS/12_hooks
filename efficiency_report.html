비용 절감 개선안 (예상 $ 기준)

1. Opus → Sonnet 라우팅 (작업 난이도별)
~$46 (~24%)

간단한 리팩터/리드/테스트 실행은 Sonnet으로 이관. /fast 토글 또는 --model sonnet 세션.

Why: Opus 가격 = Sonnet × 5. 30%만 다운그레이드해도 큰 폭 절감.

2. 장시간 세션 /compact 적극 사용
~$25

상위 14개 세션이 비용의 대부분을 차지. 매 150-200 turn마다 /compact로 절반 이상 cache read 절감 가능.

Why: 세션 길어질수록 매 turn 누적 컨텍스트를 re-read 과금. 컴팩션이 요약으로 교체.

3. 이미지 첨부 세션 관리
~$0

이미지는 장당 ~20-60k 토큰. 확인 후에도 세션 내내 캐시 유지됨. 짧게 보고 즉시 /compact.

Why: 이미지는 가장 비싼 페이로드. 불필요하게 오래 유지되면 cache_read 누적.

4. Cache TTL 1h → 5m 전환
~$8

짧은 세션엔 1h 프리미엄($30/M) 불필요. 5m($18.75/M)로 충분. ANTHROPIC_CACHE_TTL=5m env 설정.

Why: 1h 프리미엄은 30분+ 세션에서만 회수. 단기 세션엔 순수 낭비.

5. 세션 scope 축소 & 재진입
~$0

작업 단위별 세션 분리. --continue 대신 새 세션. CLAUDE.md/MEMORY.md가 컨텍스트 이관.

Why: 한 세션 내 컨텍스트 누적 → 매 turn cache_read 선형 증가. 짧은 세션이 효율적.

6. 중복 Read 제거
~$1

8건의 redundant read 감지. Grep/Glob → Read 순서. 한 번 읽은 파일은 컨텍스트 내에서 참조.

Why: 재Read는 cache write + 이후 매 turn cache read로 이중 과금.

예상 누적 절감 (단순 합산)
~$79 / $192 (~41%)

항목 간 중복 고려 시 실제로는 30–40% 수준 기대. 세션당 평균 $23.95 → $14.04.

즉시 실행 권장

  1. settings.json에 env: {"ANTHROPIC_CACHE_TTL":"5m"} — 단기 세션 즉시 감소.
  2. CLAUDE.md에 "200k 토큰 초과 시 /compact" 명시 — 상위 세션은 모두 이 규칙 위반.
  3. Sonnet 기본, Opus는 Plan/복잡 리팩터에 제한.
  4. 이미지 업로드 후 즉시 /compact.
  5. Grep/Glob 우선 탐색 규율.
